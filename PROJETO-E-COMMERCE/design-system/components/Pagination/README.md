Paginação (`nav.us-pagination`) do catálogo e das tabelas do painel.

## Estados
Normal; Hover (`navy-50`); Focus (contorno 3px); Active/página atual (`aria-current="page"`, fundo `navy-900`); Disabled (anterior na primeira página, `aria-disabled`). Loading: a lista acima mostra skeleton, a paginação fica como está.

## Regras
- Mostra primeira, atual ±1 e última, com reticências.
- Sempre informa o intervalo: "Mostrando 1–24 de 280 produtos".
- No mobile: só Anterior / Próxima + "Página 2 de 12".
