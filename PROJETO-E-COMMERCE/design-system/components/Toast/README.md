Notificação temporária (`.us-toast`) que confirma uma ação sem tirar a pessoa da tela — produto adicionado, status atualizado, falha ao salvar.

## Regras
- Fica 5 s; com ação ("Ver carrinho", "Tentar de novo") fica até ser fechado ou usado.
- Canto inferior central no mobile, inferior direito no desktop, acima do conteúdo.
- `role="status"` para sucesso e informação; `role="alert"` para erro.
- Nunca é o único lugar de uma informação importante.
