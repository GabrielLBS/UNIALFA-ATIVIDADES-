Menu (`.us-menu`) em duas formas: suspenso no header (conta) e navegação lateral de Minha conta.

## Estados
Normal; Hover (`navy-50`); Focus (contorno 3px); Active/página atual (`aria-current="page"`, fundo `navy-100`, negrito); Disabled (`aria-disabled`, texto `text-muted`, rótulo "em breve"); Danger (Sair). Loading, error e success não se aplicam a itens de menu.

## Regras
- Todo item leva a uma tela real do protótipo — nada de "seção não implementada".
- Menu suspenso abre com Enter/Espaço, navega com setas, fecha com Esc.
- No mobile, a navegação lateral vira uma lista no topo de Minha conta.
