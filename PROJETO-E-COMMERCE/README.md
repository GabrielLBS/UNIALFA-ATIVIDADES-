## Decisões do projeto

1. **Escopo completo com dados de demonstração.** O backend atual só tem o módulo de clientes (login, perfil e endereços). Telas de catálogo, carrinho, checkout, pedidos e área administrativa são projetadas com conteúdo rotulado como **Demonstração**.
2. **Identidade visual:** azul-marinho atual do UtiliStore (`#112058` / `#1c3080`) como cor principal; laranja como cor de destaque para ofertas e botões de compra (`#C2410C` com texto branco, para atender ao contraste WCAG AA).
3. **Backend não é alterado** pelo projeto de UX; as telas seguem o contrato das rotas existentes.
