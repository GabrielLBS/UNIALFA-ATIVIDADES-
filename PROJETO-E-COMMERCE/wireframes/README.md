## Convenções

- Selo tracejado **DEMONSTRAÇÃO**: dado sem backend.
- Selo preto **DADOS REAIS DA API**: dado de rota existente; "PENDENTE" = rota escrita, aguardando correção do backend.
- Botão com contorno tracejado: ação de compra (será laranja `orange-700` na alta fidelidade).
- Círculos numerados: pontos explicados nas justificativas (Entrega 12).
- Caixas tracejadas: estados alternativos (erro, sucesso, vazio).

Os arquivos `.dc.html` são o código-fonte das telas do canvas.
